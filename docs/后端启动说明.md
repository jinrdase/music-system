# 后端启动说明

## 环境

- JDK 17，Spring Boot 4.0.8。
- MySQL 8.0，开发库端口 3307，数据库 `music_system`。
- Redis 6379。
- Maven 用户设置文件：`$env:USERPROFILE\.m2\settings.xml`；启动前可用 Maven `help:evaluate` 确认本地仓库位置。
- Spring 需要环境变量 `JWT_SECRET`；不要把 JWT 密钥写入仓库。IDEA 已打开时，更新用户变量后需完全退出再启动 IDEA，或在仅本机运行配置中注入。
- 当前 Windows 用户级 `JWT_SECRET` 已设置为与当前运行实例一致的值；新开 PowerShell 会继承。已打开的 IDEA 需完全退出后重新启动才能读取。

## 启动

PowerShell：

```powershell
cd D:\IntelliJ\music-system
mvn -s "$env:USERPROFILE\.m2\settings.xml" spring-boot:run
```

成功时日志应包含 Tomcat 启动端口 8080、Redisson 连接 Redis、Hikari 数据源启动及 `Started MusicSystemApplication`。

如果端口已占用，先用 `Get-NetTCPConnection -LocalPort 8080 -State Listen` 查看 PID，再核对该进程身份和当前连接；不要直接结束未知进程。

## 数据库迁移

应用不会自动执行 `sql/` 中的 SQL。先备份开发库、只读检查表结构，再执行对应的单个增量迁移。不要在已有库运行全量 `sql/music_system.sql` 覆盖业务数据。审计表已部署，备份和执行记录见全项目测试报告。

健康检查：`GET http://localhost:8080/api/test/hello`。登录/受保护 API 需要 `JWT_SECRET` 与 JWT Bearer token。
