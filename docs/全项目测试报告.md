## 4. 模拟支付缺陷与修复

发现原代码虽然设置 `pay.mock-enabled=true`，创建支付仍无条件要求支付宝私钥，导致模拟支付不可用。已调整为模拟模式只创建本地支付记录，前端订单页调用既有 `/api/payment/mock-pay/{paymentNo}`；真实支付模式仍生成支付宝收银台。

修复通过 Maven 编译、前端构建和真实接口验证。后续自动化与管理员流程继续生成 QA 用户、订单、支付、退款及审计记录；具体数据保留在本地开发数据库中，不会自动清理。模拟支付不等于支付宝沙箱或真实资金验证。
