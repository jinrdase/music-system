# music-system 后端接口文档

更新时间：2026-11-01。接口以 `src/main/java/com/music/musicsystem/controller` 的当前源码为准。

## 通用约定

- 后端默认地址：`http://localhost:8080`；接口统一以 `/api` 开头。
- 除注册、登录、健康检查和支付宝通知外，`WebConfig` 当前会拦截 `/api/**` 并校验 JWT。请求头格式：`Authorization: Bearer <token>`。
- 登录响应字段为 `data.token`、`data.userInfo`；用户角色字段为 `userInfo.role`。后台代码校验 `admin` 或 `super_admin`，用户角色管理中只有 `super_admin` 能修改角色。
- 统一响应为 `{ "code": 200, "message": "...", "data": ... }`。业务失败目前可能仍是 HTTP 200，客户端必须同时判断 `code`。
- DTO 的校验以 Controller 上的 `@Validated`/`@Valid` 和 DTO 注解为准。分页参数通常为 `current`、`size`。
- 所有会创建订单、更新库存、支付、退款、上传文件或修改后台数据的接口均应在专用测试数据上调用。

## 用户认证和资料

| 方法 | 路径 | 登录 | 请求/说明 |
|---|---|---:|---|
| POST | `/api/user/register` | 否 | JSON：`username,password,confirmPassword,nickname,phone,email`；用户名 4–20 位，只允许字母数字下划线，密码 6–20 位 |
| POST | `/api/user/login` | 否 | JSON：`username,password`；返回 `data.token`、`data.userInfo` |
| GET | `/api/user/info` | 是 | 当前用户信息 |
| PUT | `/api/user/profile` | 是 | JSON：`nickname,phone,email,avatar` |
| PUT | `/api/user/password` | 是 | JSON：`oldPassword,newPassword,confirmPassword`；成功后应重新登录 |
| POST | `/api/user/avatar` | 是 | multipart 字段 `file`；仅 JPG/PNG，最大 2 MB |

## 地址和购物车

地址 JSON：`receiverName,receiverPhone,province,city,district,detailAddress,isDefault`。

| 方法 | 路径 | 请求/说明 |
|---|---|---|
| POST | `/api/address/add` | 新增地址 |
| GET | `/api/address/list` | 当前用户地址列表 |
| GET | `/api/address/default` | 当前默认地址 |
| GET | `/api/address/detail/{addressId}` | 当前用户地址详情 |
| PUT | `/api/address/update/{addressId}` | 更新地址，JSON 同新增 |
| PUT | `/api/address/setDefault/{addressId}` | 设置默认地址 |
| DELETE | `/api/address/delete/{addressId}` | 删除本人地址 |
| POST | `/api/cart/add` | JSON：`albumId,quantity` |
| GET | `/api/cart/list` | 当前购物车汇总与商品 |
| PUT | `/api/cart/updateQuantity/{cartId}?quantity=1` | 更新数量 |
| PUT | `/api/cart/toggleSelect/{cartId}?isSelected=1` | 选择/取消单项，值为 0/1 |
| PUT | `/api/cart/toggleSelectAll?isSelected=1` | 全选/全不选 |
| DELETE | `/api/cart/remove/{cartId}` | 删除单项 |
| DELETE | `/api/cart/batchRemove` | JSON 数组：购物车 ID |
| DELETE | `/api/cart/clear` | 清空本人购物车 |
| DELETE | `/api/cart/clearInvalid` | 清理失效项 |

## 订单、支付和退款

| 方法 | 路径 | 请求/说明 |
|---|---|---|
| POST | `/api/order/create` | JSON：`albumId,quantity,addressId,remark`；实物商品必须提供地址 |
| POST | `/api/order/createFromCart` | JSON：`addressId,remark`；按当前已选购物车商品结算 |
| GET | `/api/order/my?current=1&size=10` | 本人订单分页 |
| GET | `/api/order/{orderNo}` | 本人订单详情 |
| GET | `/api/order/{orderNo}/items` | 订单明细；本人或管理员 |
| POST | `/api/order/cancel/{orderNo}` | 取消本人待支付订单 |
| PUT | `/api/order/ship/{orderNo}` | 管理员发货；JSON：`carrier,trackingNo` |
| POST | `/api/order/confirmReceipt/{orderNo}` | 本人确认收货 |
| GET | `/api/order/{orderNo}/digital-content` | 已支付且有权访问时取数字内容 |
| GET | `/api/order/{orderNo}/digital-content/{itemId}` | 订单明细级数字内容 |

| POST | `/api/payment/cancel/{paymentNo}` | 取消本人待支付单 |

| POST | `/api/refund/apply` | JSON：`orderId,reason,description,images,returnCarrier,returnTrackingNo` |
| GET | `/api/refund/my?current=1&size=10` | 本人退款申请分页 |
| GET | `/api/refund/admin/pending?current=1&size=10` | 管理员待审核退款 |
| PUT | `/api/refund/admin/{applicationId}/review` | 管理员 JSON：`approved,auditRemark`；拒绝需填写原因 |

## 管理后台

后台路由要求 JWT，Controller 进一步检查角色。部分修改仅允许 `super_admin`。

| 方法 | 路径 | 参数/说明 |
|---|---|---|
| GET | `/api/admin/stats/overview` | 运营统计 |
| GET | `/api/admin/stats/albums-top` | 专辑销量榜 |
| GET/POST | `/api/admin/albums` | 列表分页/新增专辑 |
| PUT | `/api/admin/albums/{albumId}` | 更新专辑 |
| PUT | `/api/admin/albums/{albumId}/status?status=1` | 上下架 |
| GET | `/api/admin/songs?albumId={id}&current=1&size=20` | 查询专辑歌曲 |
| POST | `/api/admin/songs` | 新增歌曲 |
| PUT | `/api/admin/songs/{songId}` | 更新歌曲 |
| GET | `/api/admin/users?current=1&size=10&keyword=` | 查询用户 |
| PUT | `/api/admin/users/{userId}/status` | JSON：`status` |
| PUT | `/api/admin/users/{userId}/role` | JSON：`role`；仅超级管理员可用 |
| GET/POST | `/api/admin/blind-boxes` | 查询/新增盲盒 |
| PUT | `/api/admin/blind-boxes/{boxId}/status?status=1` | 上下架 |
| POST | `/api/admin/blind-boxes/{boxId}/prizes` | 新增奖品 |
| PUT | `/api/admin/blind-boxes/{boxId}/prizes/{prizeId}` | 更新奖品 |
| GET | `/api/admin/orders?current=1&size=10` | 后台订单分页和筛选 |
| POST | `/api/admin/media/image`、`/api/admin/media/audio` | multipart `file`，管理员媒体上传 |
| GET | `/api/admin/audit-logs` | 分页及 `operatorUserId,httpMethod,requestPath,from,to` 筛选。开发数据库表已安装；需管理员 JWT |

管理员操作审计还会自动记录 `PUT /api/order/ship/{orderNo}` 和 `/api/refund/admin/**`（包括待审核列表与审核动作）；不记录审计日志查询自身。审计行中的 `responseStatus` 是 HTTP 状态，不一定等于统一响应体的 `code`。

## 当前权限和验证边界

- QA 管理员已创建并通过管理员 API 和浏览器路由测试。发货、收货、退款拒绝闭环也已使用隔离 QA 数据验证；没有修改现有用户角色。
- 最新审计路径补丁在验证实例 8082 上完成启动和审计写入检查；当前已运行的 8080 实例需重启后才会加载该补丁。
- 浏览目录接口目前也受 JWT 拦截，游客访问首页目录请求会触发未登录响应；这是当前后端拦截规则，不要在前端伪装成匿名目录接口成功。
