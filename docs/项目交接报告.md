# music-system 项目交接报告

更新时间：2026-11-01
工作区：`D:\IntelliJ\music-system`

## 项目定位和版本

音乐数字专辑与周边电商。后端 Java 17、Spring Boot 4.0.8、MyBatis-Plus 3.5.17；MySQL 8.0.46（本地 3307）、Redis 6379、Redisson 3.35.0、JJWT 0.12.6。前端位于 `frontend/`，采用 Vue 3、Vite、Vue Router、Pinia、Axios、Element Plus、Playwright。开发后端端口 8080、前端端口 5173。

## 当前实现

- 用户注册/登录、JWT、资料/密码/头像、权限拦截。
- 专辑/歌曲浏览和播放计数；实物/数字产品区分。
- 地址维护、购物车、单件/已选购物车下单、订单快照、订单状态、物流和数字内容授权。
- 模拟支付；支付宝沙箱代码与回调路径存在，但沙箱凭据及回调未验收。
- 退款申请和审核服务；已用 QA 管理员验证退款拒绝流程。批准退款路径尚未执行，避免触发退款资金操作。
- 盲盒购买待支付，支付成功后服务端事务抽取、记录结果及库存处理。
- 管理后台专辑、歌曲、用户、订单、盲盒、统计、媒体上传页面和 API。
- 本轮新增审计记录 Entity/Mapper/Service/Controller、筛选分页、拦截器写记录、Vue 页面/路由/菜单，以及数据库迁移脚本。已在本地库安装审计表。
- Playwright 覆盖注册/登录/购物车订单模拟支付退款流程、未登录权限守卫、管理员后台所有路由和审计页面。使用本机 Edge。

- `/api/**` 当前都经过 JWT 拦截，注册、登录、测试、支付宝回调除外；匿名目录浏览目前不支持。
- 管理员路由检查 `admin`/`super_admin`。`PUT /api/admin/users/{id}/role` 只允许 `super_admin`。
- 不要通过手动改现有用户角色、前端注入 Token 或模拟响应来通过权限测试。

## 启动和测试

```powershell
# 后端
cd D:\IntelliJ\music-system
mvn -s "$env:USERPROFILE\.m2\settings.xml" spring-boot:run

# 前端（另开 PowerShell）
cd D:\IntelliJ\music-system\frontend
npm run dev

# 验证
cd D:\IntelliJ\music-system
mvn -s "$env:USERPROFILE\.m2\settings.xml" clean compile
mvn -s "$env:USERPROFILE\.m2\settings.xml" test
cd frontend
npm run build
npm run test:e2e
```
