# 前端启动说明

## 开发模式

先按 `docs/后端启动说明.md` 启动后端 8080，再另开 PowerShell：

```powershell
cd D:\IntelliJ\music-system\frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。Vite 将 `/api` 和 `/media` 代理给 `http://localhost:8080`。

## 构建

```powershell
cd D:\IntelliJ\music-system\frontend
npm run build
```

输出为 `frontend/dist/`，当前不自动复制进后端静态目录。生产环境需托管静态构建结果并配置 `/api`、`/media` 反向代理。

## 浏览器自动化测试

```powershell
cd D:\IntelliJ\music-system\frontend
npm run test:e2e
```

测试需要运行中的后端、开发数据库和本机 Microsoft Edge。用户流程会留下标识为 `e2eqa*` 的测试数据，不自动清理。后台测试需要已获批准的 QA 管理员账号，通过临时环境变量 `E2E_ADMIN_USERNAME`、`E2E_ADMIN_PASSWORD` 传递；测试结束后删除进程环境变量。

在 PowerShell 中可从 Git 忽略的本地凭据文件设置测试进程变量（命令不会打印值）：

```powershell
$qaLines = Get-Content ..\local-test-credentials\qa-admin.txt
foreach ($line in $qaLines) {
  if ($line -match '^username=(.*)$') { $env:E2E_ADMIN_USERNAME = $Matches[1] }
  elseif ($line -match '^password=(.*)$') { $env:E2E_ADMIN_PASSWORD = $Matches[1] }
}
npm run test:e2e
Remove-Item Env:E2E_ADMIN_USERNAME, Env:E2E_ADMIN_PASSWORD -ErrorAction SilentlyContinue
```
